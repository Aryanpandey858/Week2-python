# Week 2 - Python

Assignments and mini project for Week 2 (data storage, file I/O, CRUD logic).

## Programs

| File | Description |
|------|-------------|
| `contact_book.py` | Contact book using a dictionary: add, search, update, delete |
| `word_counter.py` | Counts lines, words and characters of a text file (`sample.txt`) |
| `json_reader.py` | Loads a JSON file (`data.json`) and prints formatted output |
| `student_management.py` | Mini project: student records stored in `students.csv` (add, delete, search) |

## How to run

```
python contact_book.py
python word_counter.py
python json_reader.py
python student_management.py
```
